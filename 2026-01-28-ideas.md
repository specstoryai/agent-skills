# Specstory Skills Ideas

**Date**: 2026-01-28

## Context

Building skills for the `agent-skills` repo that work with users' local `.specstory/history` directories. Specstory captures full AI conversation histories including timestamps, prompts, responses, tool calls, thinking blocks, and @file references.

---

## Top 5 Utility Ideas (by trending potential)

### 1. Code Decision Archaeology
**Semantic search: "Why did we decide X?"**
- **Why it trends**: Every developer asks "why did we do it this way?" - specstory uniquely captures the *reasoning*, not just outcomes
- **Data used**: `<think>` blocks, user prompts, agent explanations, @file references
- **Complexity**: Medium-High (needs semantic search/embeddings)
- **Viral potential**: Very High - "I asked my codebase why we chose PostgreSQL and it showed the exact conversation from 3 months ago"

### 2. Session Resume / Context Handoff
**Summarize past session to continue work**
- **Why it trends**: Solves #1 pain point - losing context between sessions
- **Data used**: Session headers, chronological turns, tool use patterns, files touched
- **Complexity**: Low-Medium
- **Viral potential**: High - "Never lose context again"

### 3. ADR Generator
**Auto-generate Architecture Decision Records from conversations**
- **Why it trends**: ADRs are best practice but tedious; history contains the decision-making process
- **Data used**: `<think>` reasoning, design doc references, alternatives explored
- **Complexity**: Medium
- **Viral potential**: High - Appeals to tech leads and anyone maintaining docs

### 4. Developer Productivity Dashboard
**Analyze coding patterns, peak hours, time per feature**
- **Why it trends**: Quantified self for developers
- **Data used**: ISO timestamps, session durations, tool call counts, files per session
- **Complexity**: Low (pure analytics)
- **Viral potential**: Medium-High - Dashboards are inherently shareable

### 5. Prompt Effectiveness Analyzer
**Which prompt styles work best?**
- **Why it trends**: Meta-learning about AI tools
- **Data used**: User prompt patterns, follow-up corrections, session length as success proxy
- **Complexity**: Medium-High
- **Viral potential**: Medium

## Top 5 Funny Ideas (by shareability)

### 1. Yak Shave Tracker
**Detect rabbit hole sessions**
- **Why it's funny**: "Started fixing a button, ended up rewriting the build system"
- **Data used**: Initial prompt vs files touched, session duration outliers, topic drift
- **Complexity**: Medium
- **Viral potential**: Extremely High - Every developer will share their yak shave score

### 2. 3am Coding Detector
**Stats on late-night decisions**
- **Why it's funny**: Correlate late-night coding with code quality and next-day fixes
- **Data used**: Timestamps, tool error rates, sessions fixed the next day
- **Complexity**: Low
- **Viral potential**: Very High - "Your worst decisions were made at 2:47am"

### 3. Rubber Duck Score
**How often did you answer your own question?**
- **Why it's funny**: Celebrates the magic moment when explaining the problem reveals the solution
- **Data used**: User prompt length vs session length, self-interruptions
- **Complexity**: Medium
- **Viral potential**: High - Beloved developer experience, meme-worthy

### 4. Code Regret Tracker
**Find all "we should refactor this later"**
- **Why it's funny**: Technical debt shaming leaderboard
- **Data used**: "later", "TODO", "hack", "workaround" patterns + associated files
- **Complexity**: Low
- **Viral potential**: High - Tech debt shaming is its own genre

### 5. AI Dependency Score
**How dependent are you on AI assistance?**
- **Why it's funny**: Playful but pointed metric
- **Data used**: Session count over time, prompt complexity, model usage patterns
- **Complexity**: Low
- **Viral potential**: Medium-High - Sparks friendly competition
