# Specstory Skills Ideas

**Date**: 2026-01-28

## Context

Building skills for the `agent-skills` repo that work with users' local `.specstory/history` directories. Specstory captures full AI conversation histories including timestamps, prompts, responses, tool calls, thinking blocks, and @file references.

---

## Top 5 Utility Ideas (by trending potential)

### 1. Code Decision Archaeology
**Semantic search: "Why did we decide X?"**
- **Why it trends**: Every developer asks "why did we do it this way?" - specstory uniquely captures the *reasoning*, not just outcomes
- **Data used**: `<think>` blocks, user prompts, agent explanations, @file references
- **Complexity**: Medium-High (needs semantic search/embeddings)
- **Viral potential**: Very High - "I asked my codebase why we chose PostgreSQL and it showed the exact conversation from 3 months ago"

### 2. Session Resume / Context Handoff
**Summarize past session to continue work**
- **Why it trends**: Solves #1 pain point - losing context between sessions
- **Data used**: Session headers, chronological turns, tool use patterns, files touched
- **Complexity**: Low-Medium
- **Viral potential**: High - "Never lose context again"

### 3. ADR Generator
**Auto-generate Architecture Decision Records from conversations**
- **Why it trends**: ADRs are best practice but tedious; history contains the decision-making process
- **Data used**: `<think>` reasoning, design doc references, alternatives explored
- **Complexity**: Medium
- **Viral potential**: High - Appeals to tech leads and anyone maintaining docs

### 4. Developer Productivity Dashboard
**Analyze coding patterns, peak hours, time per feature**
- **Why it trends**: Quantified self for developers
- **Data used**: ISO timestamps, session durations, tool call counts, files per session
- **Complexity**: Low (pure analytics)
- **Viral potential**: Medium-High - Dashboards are inherently shareable

### 5. Prompt Effectiveness Analyzer
**Which prompt styles work best?**
- **Why it trends**: Meta-learning about AI tools
- **Data used**: User prompt patterns, follow-up corrections, session length as success proxy
- **Complexity**: Medium-High
- **Viral potential**: Medium

- **Complexity**: Low
- **Viral potential**: High - Tech debt shaming is its own genre

### 5. AI Dependency Score
**How dependent are you on AI assistance?**
- **Why it's funny**: Playful but pointed metric
- **Data used**: Session count over time, prompt complexity, model usage patterns
- **Complexity**: Low
- **Viral potential**: Medium-High - Sparks friendly competition

## Multi-Source Skills (Specstory + External Data)

These combine specstory history with other data sources for powerful synergies.

### 1. Commit Whisperer
**Specstory + Git (commits, diffs, blame)**
- **What it does**: Links every git commit to the AI conversation that produced it. `git blame` on steroids - click any line to see the original AI conversation with full reasoning
- **Why powerful**: Git blame shows WHO and WHEN, but never WHY. Combined, you get time travel into every decision
- **Viral potential**: EXTREME - "I ran git blame and it showed me the exact AI conversation from 6 months ago"

### 2. PR Story Generator
**Specstory + GitHub/GitLab API (PRs, issues, reviews)**
- **What it does**: Auto-generates rich PR descriptions by mining the AI conversations that produced the code. Includes decision rationale, alternatives explored, links to thinking blocks
- **Why powerful**: PRs often lack context about WHY. The conversation history contains exactly this
- **Viral potential**: VERY HIGH - Every PR reviewer hates "what does this do?" - this solves it

### 3. Sentry Session Linker
**Specstory + Error Tracking (Sentry, logs)**
- **What it does**: When an error hits Sentry, finds the specstory session where that code was written. Shows original conversation, reasoning, and any concerns the AI raised
- **Why powerful**: Debugging is 10x faster when you see the CONTEXT of when buggy code was written
- **Viral potential**: VERY HIGH - "Sentry showed me the exact AI conversation where we introduced the bug"

### 4. Standup Summarizer
**Specstory + Calendar (Google Calendar, meetings)**
- **What it does**: Before standup, generates a summary of your AI coding sessions since last meeting. "Yesterday I worked on auth refactor (3 sessions, 2 hours), explored caching options (rejected Redis), fixed 2 bugs"
- **Why powerful**: Standup prep is tedious. Auto-generates "what I did" from actual activity
- **Viral potential**: HIGH - "I never have to think about what to say in standup again"

### 5. Issue Autopilot
**Specstory + Linear/Jira (tickets, sprints) + Git**
- **What it does**: When you start coding, suggests relevant past specstory sessions. When done, auto-updates ticket with summary of work, files changed, AI-assisted decisions
- **Why powerful**: Closes the loop between project management and coding
- **Viral potential**: HIGH - PMs love this. "My ticket was auto-updated with exactly what happened"

### 6. Knowledge Transfer Curator
**Specstory + Git + GitHub + Slack/Discord**
- **What it does**: For new team members, generates a curated "codebase tour" by finding important AI conversations that shaped key architecture. Combines with Slack discussions and PR reviews
- **Why powerful**: Onboarding is hard because knowledge is scattered. Creates narrative of how codebase evolved
- **Viral potential**: VERY HIGH - "New hires can see the entire decision history"

### 7. CI/CD Failure Time Machine
**Specstory + CI/CD (test results, build logs)**
- **What it does**: When CI fails, finds the specstory session where failing code was written. Shows if AI warned about test coverage or suggested tests that weren't added
- **Why powerful**: "The AI literally suggested this test and I said 'later'" - now you can see those moments
- **Viral potential**: HIGH - Humbling but valuable for learning

### 8. Dependency Decision Tracker
**Specstory + package.json + npm/PyPI (changelogs, security)**
- **What it does**: Links every dependency to the conversation where it was added. When vulnerabilities appear, shows original reasoning for adding it
- **Why powerful**: "Why do we use lodash again?" - now answered with the exact conversation
- **Viral potential**: HIGH - Package management is painful, this adds decision history

### 9. Sprint Retro Generator
**Specstory + Linear/Jira + Git + Calendar**
- **What it does**: Auto-generates sprint retro content analyzing AI sessions. What went well (quick sessions), what was hard (long sessions), what was learned (new patterns)
- **Why powerful**: Retros are often vague. This provides data-driven insights
- **Viral potential**: HIGH - Agile teams love automated retro prep

### 10. Slack Context Bridge
**Specstory + Slack/Discord**
- **What it does**: Links Slack discussions about features to AI sessions that implemented them. When someone asks "how does X work?", surfaces the relevant conversation
- **Why powerful**: Team knowledge is fragmented between chat and code. This bridges them
- **Viral potential**: MEDIUM-HIGH - Teams value better knowledge sharing
